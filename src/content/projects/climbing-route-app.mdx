A cross-platform mobile app for gym climbers to create, share, rate, and discover routes
within their home gyms. Built solo and currently in closed beta with an active testing cohort.

## Stack

- React Native (TypeScript), native iOS and Android builds
- Firebase Cloud Functions (Node.js) serverless backend
- Firestore data model with security rules
- Jest and React Native Testing Library
